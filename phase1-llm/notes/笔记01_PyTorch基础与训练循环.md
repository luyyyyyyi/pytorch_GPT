## 一、张量 tensor（A.2）
- **是什么**：装数字的盒子，按维度分：0维标量 / 1维向量 / 2维矩阵 / 3维及以上。
- **常用操作**：`.shape`（看形状，最常用）、`.reshape/.view`（重排）、`.T`（转置）、`@` 或 `.matmul()`（矩阵乘法，神经网络的核心运算）。
- **dtype**：深度学习几乎都用 `float32`；`.to(torch.float32)` 转类型。
- **内存细节**：`torch.tensor(ary)` 拷贝；`torch.from_numpy(ary)` 与原数组共享内存（改一个另一个也变）。

## 二、把模型看成计算图（A.3）
- 前向计算时 PyTorch 会把每一步运算记录成一张「计算图」，每个节点都知道自己的局部导数。
- 最小模型：`z = x1*w1 + b → a = sigmoid(z) → loss`。

## 三、自动求导 autograd（A.4）
- 参数加 `requires_grad=True`，PyTorch 就会帮它自动算梯度。
- `loss.backward()` 一行算出所有参数的梯度，存进各自 `.grad`。

## 四、训练循环（A.7）★核心 — 五步
```
1. 前向:  logits = model(x)            # 同时记录计算图
2. 打分:  loss = 损失函数(logits, 标准值)  # 错多少
3. 清零:  optimizer.zero_grad()        # 清掉上一轮梯度（梯度会累加，必须清）
4. 反向:  loss.backward()              # 链式法则自动求梯度 → 存进 .grad
5. 更新:  optimizer.step()             # 参数 -= lr × 梯度，沿负梯度下山
重复多轮(epoch) → loss 越来越小 → 模型越来越准
```
- 实测 loss 从 0.75 → 0.00，模型在玩具数据上学会了二分类。
- 从玩具网络到 GPT，**训练循环都是这同一套**。

## 五、四个深挖的问题（今天的重点收获）

### 1) optimizer.step() 怎么更新参数？
- 用的是 **SGD**，核心公式：`新参数 = 旧参数 − lr × 梯度`。
- `step()` 内部对每个参数做这个减法（这段在 PyTorch 内部，notebook 里只调用 `optimizer.step()` 一行）。
- 验证：A.4 中 `w1=2.2`、`grad=-0.0898`、`lr=0.5` → 新 w1 = 2.2 − 0.5×(−0.0898) = 2.2449。
- **优化器有很多种**（都是梯度下降的变体）：SGD → +Momentum(惯性) → 自适应(RMSProp) → **Adam/AdamW**（训 GPT 的默认）。换优化器只改一行。

### 2) 为什么梯度是「loss 上升最快」的方向？
- 一维：导数=斜率，正→增大参数 loss 上升。
- 多维：梯度是各参数偏导打包成的向量，指向 loss 上升最快的方向。
- 原因：沿单位方向 u 的变化率 = 梯度·u（点积），u 与梯度同向时最大。
- 所以更新用 **减去梯度**（负梯度=下降最快）。类比：朝最陡上坡的反方向下山。

### 3) loss 怎么计算？（损失函数）
- loss = 给预测打「错得多离谱」的分，越大越错。
- **二分类**：binary cross entropy `−[y·log(a)+(1−y)·log(1−a)]`，重罚「自信的错误」。验证：y=1,a≈0.918 → −log(0.918)≈0.0852（和 notebook 一致）。
- **多分类 / GPT 预测下一个词**：cross entropy = `−log(正确类别的概率)`（PyTorch 的 cross_entropy 自带 softmax）。
- **回归**：MSE = 差值的平方均值。
- ★ 训 GPT 用 cross entropy：把高概率押在「真实的下一个词」上，loss 就小。

### 4) 标准值（正确答案）从哪来？
- 不是算出来的，是**数据自带**，用来对答案、算 loss。
- 来源：人工标注（如垃圾短信）/ 客观事实（房价）/ **自监督**。
- ★ GPT 用自监督：「正确的下一个词」就是原文里实际的下一个词，**无需人工标注**，所以能用海量文本训练。
- 训练集（边学边对答案）vs 测试集（学完用没见过的数据检验，防止「考前看答案」式过拟合）。

### 5) loss.backward() 怎么自动求梯度？（反向传播）
- 顺着计算图，用**链式法则**从 loss 往回算到每个参数，把每一环局部导数相乘。
- 验证 `∂loss/∂w1 = ∂loss/∂a · ∂a/∂z · ∂z/∂w1`：
  - ∂z/∂w1 = x1 = 1.1
  - ∂a/∂z = a(1−a) ≈ 0.0753
  - ∂loss/∂a = −1/a ≈ −1.089
  - 相乘 ≈ −0.0898 ✅（正是 notebook 的 grad_L_w1）
- 叫「反向」因为从 loss 往输入方向回推。autograd 让上亿参数也只需 `backward()` 一行。

---

## 闭环总结（模型怎么学）
> 数据给标准答案 → loss 打分（错多少）→ backward 求梯度（往哪改）→ step 更新（改一点）→ 重复 → 变准。
