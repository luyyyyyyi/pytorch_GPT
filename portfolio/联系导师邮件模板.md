# 联系科研导师 / 套磁邮件模板

> 原则：简短（学生邮件老师每天收很多）、有针对性（读过他论文）、有证据（你已经动手做了东西）。
> 控制在手机一屏内。附件放技术报告 + GitHub 链接。

---

## 模板（中文）

**主题：** 大二学生求加入课题组 - 已复现 XX 方向项目（附作品）

尊敬的 X 老师：

您好！我是 XX 大学计算机专业大二学生 XXX。我对您在 **<具体研究方向，如 AI for Science / 计算材料>** 的工作很感兴趣，尤其是您 <某篇论文/某个课题> 中关于 <具体点> 的思路。

为了打基础，我已经自学并动手完成了几个项目：
- <项目一，一句话 + 量化结果>
- <项目二，一句话 + 量化结果>

相关代码和实验报告在这里：<GitHub 链接>。

我有 Python 和 C/C++ 基础，能独立跑通工具链并做实验，时间上 <每周可投入 X 小时 / 假期可全职>。希望有机会参与您课题组的工作，从打杂做起也愿意。

期待您的回复，谢谢！

此致
XXX
<邮箱 / 电话 / GitHub>

---

## 几个要点
- **一定先读 1-2 篇他的论文**，邮件里点出具体内容，证明不是群发。
- **附证据**：你的 GitHub + 技术报告，比说一堆"我很有热情"管用。
- **降低对方成本**：明确说能投入多少时间、愿意做基础工作。
- **没回复很正常**：一周后可礼貌跟进一次，或多发几位老师。
