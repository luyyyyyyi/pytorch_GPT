# 简历项目描述模板（含示例）

> 原则：动词开头 + 具体技术 + 可量化结果。避免"参与""了解""学习"这类虚词。
> 一个项目 2-4 条 bullet，主打阶段二（差异化最强）。

## 写法公式
`[做了什么动作] + [用什么技术/工具] + [达到什么可量化结果]`

好动词：实现 / 复现 / 优化 / 量化 / 部署 / 对比评测 / 提交 PR
弱动词（避免）：参与 / 了解 / 学习 / 接触

---

## 示例一：端侧推理（阶段二 · 主打）
**端侧 LLM 量化部署与性能评测 ｜ llama.cpp (C/C++)**
- 基于 llama.cpp 在本地离线部署 1.5B 量级 LLM，实现 CLI 与 HTTP server 两种推理方式。
- 将模型量化为 Q8/Q5/Q4/Q2 共 4 个等级，系统评测体积、内存、吞吐(tokens/s)与质量的权衡。
- 阅读 ggml 量化 kernel 与 KV cache 实现，向上游提交 1 个 PR（文档/测试/小修复）。

## 示例二：LLM 复现（阶段一）
**从零实现并训练 GPT 语言模型 ｜ PyTorch**
- 手写多头自注意力、因果掩码与 Transformer Block，从零实现 GPT 结构。
- 复现 GPT-2 预训练流程，在 X 语料上训练出可生成连贯文本的小模型，loss 由 A 降至 B。
- 实现 BPE 分词器并训练自定义 tokenizer。

- 能量/力预测误差达到 <填具体数值>，并接入 LAMMPS 驱动一段 MD 模拟。
